# Top 10 Command Palette Commands

## VS Code

| # | Command | Notes |
|---|---------|-------|
| 1 | **Format Document** | Auto-format the current file |
| 2 | **Preferences: Open Settings** | Most-reached-for settings entry |
| 3 | **Toggle Terminal** | Show/hide the integrated terminal |
| 4 | **Reload Window** | Essential when extensions misbehave |
| 5 | **Git: Commit** / **Git: Push** | Common git operations |
| 6 | **Transform to Uppercase / Lowercase** | Quick text transformation |
| 7 | **Toggle Word Wrap** | Quick readability toggle |
| 8 | **Sort Lines Ascending** | Sorting imports/lists |
| 9 | **View: Toggle Zen Mode** | Distraction-free coding |
| 10 | **Extensions: Install Extensions** | Managing the extension marketplace |

## Cursor

Cursor inherits VS Code's palette and adds AI-specific commands:

| # | Command | Notes |
|---|---------|-------|
| 1 | **Open Chat** (`Cmd/Ctrl+L`) | Main AI chat panel |
| 2 | **Inline Edit** (`Cmd/Ctrl+K`) | Inline AI code generation/edit |
| 3 | **Open Composer** (`Cmd/Ctrl+I`) | Multi-file AI edits |
| 4 | **Accept Suggestion** (Tab) | Accept Cursor Tab autocomplete |
| 5 | **Format Document** | Same as VS Code |
| 6 | **Cursor: New Chat** | Start a fresh chat thread |
| 7 | **Add to Chat** | Add selected code to active chat |
| 8 | **Toggle Terminal** | Same as VS Code |
| 9 | **Reload Window** | Same as VS Code |
| 10 | **Git: Commit / Push** | Same as VS Code |
