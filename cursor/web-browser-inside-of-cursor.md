## The Problem

I want to share a window for a meeting.
Inside of that window I want to:
   - show direcory trees
   - show code
   - run terminal windows
   - show a web browser ( this is the one that I did not know how to do ) 

## The Environment ~~Emacs~~ Cursor

I was an emacs user for more than a decade. So I understand
the idea of the GNU Toolset and a IDE as a window manager.



1. Simple Browser (built into Cursor/VS Code) — still your zero-install starting point. Command Palette → "Simple Browser: Show".

2. Live Preview by Microsoft (ms-vscode.live-server) — now the actively maintained option. 
   Embeds a Chromium-based preview inside a Cursor tab, supports auto-refresh on save, 
   and handles localhost dev servers well. This replaces what Browser Preview used to do.
